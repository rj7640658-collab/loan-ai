Google Sheets Serverless Data Storage Setup

Zero-backend cloud persistence via Google Apps Script Web App.

Step 1: Open Google Sheets Create a new blank sheet on sheets.new named "AI Loan Applications".
Step 2: Add Apps Script Click Extensions → Apps Script and paste the code from google_apps_script.js provided in this repo.
Step 3: Deploy as Web App Click Deploy → New deployment → Web app, set access to "Anyone", and deploy.
Step 4: Paste Web App URL Click the gear icon in the top navigation or edit .env to store the URL. All future evaluations will sync in real time!
